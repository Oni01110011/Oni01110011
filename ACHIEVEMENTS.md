# GitHub achievements

GitHub awards profile achievements automatically for qualifying activity. They cannot be assigned manually.

## Progress

- **Quickdraw** — already visible on this profile on 2026-09-26.
- **Pull Shark** — already visible on this profile on 2026-09-26.
- **YOLO** — a pull request merged without a review may qualify; the profile is the source of truth for whether GitHub has awarded it.

## Other achievements

- **Pair Extraordinaire** requires a qualifying coauthored contribution merged through a pull request. Credit actual contributors only.
- **Starstruck** depends on other users starring a repository.
- **Galaxy Brain** depends on accepted answers in eligible GitHub Discussions.
- **Public Sponsor** depends on eligible sponsorship through GitHub Sponsors.
- **Arctic Code Vault Contributor** and **Mars 2020 Contributor** relate to historical programs and cannot be earned retroactively through new activity.

Requirements and availability may change. Community explanations are not guarantees that GitHub will award a badge.
